# Portfolio Navigation Update — Resume + Contact

Focused patch for the existing Angappan Healthcare BA portfolio.

Adds Resume and Contact to desktop/mobile navigation and makes both destinations functional.

## Copy these files into the existing repository
- `src/main.tsx`
- `src/skills.tsx`
- `src/carebridge.tsx`
- `src/experience.tsx`
- `resume.html`
- `contact.html`
- `Angappan_Sabarimani_Resume.pdf`

Do not replace the entire repository with this ZIP. Copy/replace only the files listed above.

## GitHub Desktop
1. Copy the files into the local `angappan-healthcare-ba-portfolio` folder.
2. Open GitHub Desktop and review Changes.
3. Commit: `Add Resume and Contact navigation`.
4. Push to `main`.
5. Vercel should redeploy automatically.
6. Verify Resume opens the PDF and Contact opens the contact page.
7. Check both desktop and mobile menus.
