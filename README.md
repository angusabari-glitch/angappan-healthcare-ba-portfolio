## Portfolio boundaries
- CareBridge is an independent portfolio simulation using simulated data.
- RyVora is a simulated, synthetic/non-PHI portfolio application.
- Do not represent either as a client production implementation.
- Do not claim live payer connectivity, live FHIR APIs, production automation, or autonomous AI decisions.

## Before deployment
1. Replace placeholder LinkedIn/email links on the homepage if present.
2. Add the final resume PDF and connect the Resume button.
3. Verify all navigation links in a production preview.
4. Run `pnpm install` then `pnpm build` (or `npm install && npm run build`).
5. Deploy the project root to Vercel with Vite output `dist`.

## Recommended Vercel settings
- Framework: Vite
- Root directory: `./`
- Build command: `pnpm build`
- Output directory: `dist`
- Environment variables: none required by the portfolio itself
